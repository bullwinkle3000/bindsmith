How this works

A profile is two files that always travel together:

  • name.binds — the config the game reads: every action, and what control is bound to it.
  • name.json — the layout: what each bound control means, written as roles rather than device keys.

Roles are the trick. A binding says 231D0200 · Joy_YAxis, which is meaningless on any other stick. A role says pitch, which every joystick can satisfy. So a layout can be moved to new hardware — which is what Port does.

Start in Devices to describe your hardware, then Profiles to build and move layouts.
